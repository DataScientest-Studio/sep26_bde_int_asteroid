/*

Collection 'object' (comes from sbdb):


TRIM        - 'full_name', padding varies with name length
CAST        - cast to float the fields 'H, H_sigma, diameter, albedo, moid, ma, n, per, epoch, data_arc, rms, 
				e, a, q, i, om, w, all six sigma_*'; 'condition_code' (measured domain is null + '0'–'9'; 
				anything else → null + log); 'last_obs' (ISO, 2 nulls)     
DROP        - field 'neo', as it is always 'Y' (we fetched with 'neo' filter)   
DERIVE      - 'orbit_id_num' (strip non-digits from 'orbit_id'; keep the raw too)     
PRESERVE    - pdes, class, pha, orbit_id (pdes is the join key, it is never cast into a number)
ADD         - 'is_comet' (from class IN ('ETc','HTC','JFC','JFc'))

----------------

Collection 'risk' (comes from sentry_s):

TRIM      
CAST        - cast to float the fields 'h, diameter, v_inf, ip, ps_cum, ps_max, last_obs_jd'; 
				nullable and smallint for 'ts_max'
SPLIT       - 'range' to 'range_start', 'range_end' (1NF)
DROP        - 'fullname' (already exists in sbdb and here it is in worse format);
				'last_obs' ('last_obs_jd' gives same info in a better format)
RESOLVE     - 'des' to 'spkid'  
PRESERVE    - des, id

----------------

Collection 'removed' (comes from sentry_r):

CAST        - 'removed' to timestamp
RESOLVE     - 'des' to 'spkid', nullable
PRESERVE    - des

----------------

Collection 'approach' (comes from cad):

DROP        - 'h' (object level, 2NF violation)
CAST        - cast the fields to float 'jd, dist, dist_min, dist_max, v_rel, v_inf';
				'cd' to timestamp
PRESERVE    - 't_sigma_f'
DERIVE      - 'orbit_id_num'
RESOLVE     - 'des' to 'spkid'

----------------

Collection 'alias' (comes from sbdb + sentry_s):

spkid		-	sbdb.spkid
pdes		-	sbdb.pdes
full_name	-	sbdb.full_name, trimmed
sentry_des	-	sentry_s.des
sentry_id	-	sentry_s.id 

*/
